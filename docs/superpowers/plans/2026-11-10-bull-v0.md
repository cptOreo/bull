# Bull v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-subagent-driven-development (recommended) or superpowers-executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Bull v0 — a chat-first stock-discovery app and applied-literacy Academy for first-time Indian investors, running entirely offline from one committed, dated snapshot, where every figure is computed in code, every sentence passes one deterministic safety choke point, and `npm run eval` proves the ship gate.

**Architecture:** One Next.js 15 App Router app with four layers and a single dependency direction: routes/components → `lib/engine/answer.ts` → the pure engine modules (`classify`, `intake`, `metrics`, `score`, `risk`, `narrative`, `safety`, `curriculum`, `xp`) → `lib/data` (a Zod-validated, deep-frozen `data/snapshot.json`). The engine is pure TypeScript with no React, no `fs`, no `fetch` and no `process.env`; `now` is always a parameter. The only network-capable module is `lib/llm/*`, and it is inert without a key.

**Tech Stack:** Next.js 15 (App Router), TypeScript (strict), Tailwind CSS 4, Recharts, Zod, Vitest (+ Testing Library, jsdom), `tsx` for the eval harness, `localStorage` for profile and learning progress.

**Spec:** `docs/superpowers/specs/2026-11-10-bull-v0-design.md` (approved). Section references such as §7.6 point at that file.

## How to use this plan

- Run every command from the repository root: `/run/media/ravid/New Volume/ai for pm/finalprojeect`. **The path contains spaces**, so any command that mentions it must quote it. Commands that only use `npm`, `git` or relative paths need no quoting because the working directory is already the repo root.
- **One task = one commit.** Each task ends with a commit step. Do not batch tasks.
- **TDD is not optional in Phases 1, 2 and 5.** Write the failing test, run it and read the failure, then write the implementation. If a test passes before the implementation exists, the test is wrong.
- **Never weaken a test to make it pass.** If a test and the spec disagree, the spec wins: fix the code. If the spec is genuinely ambiguous, the "Decisions this plan fixes" table below resolves it; if the case is not in that table, stop and ask — do not silently choose.
- Every code step contains the complete file or the complete replacement block. Where a step edits an existing file, the exact old and new text is given.
- Where a step creates a React screen, the data flow, hooks, prop interfaces and every branch are complete; repeated Tailwind class strings are collapsed to `className="..."` with a one-line note of the intended layout. Do not treat `className="..."` as permission to omit an element or a branch.
- `npm run data:check` and `npm run eval` fail with "Cannot find module" until Tasks 11 and 69 respectively. Do not run them earlier; the plan says when.

### The invariants that must never break

1. `lib/engine/**` imports only TypeScript types, other engine modules and `lib/data` **types**. No React, no `next/*`, no `fs`, no `fetch`, no `process.env`, no `lib/llm`.
2. `answer.ts` is the only composer of user-facing answer text, and it calls `safety.inspectAnswer` before returning.
3. Components never import `lib/engine/narrative.ts`, `lib/engine/metrics.ts` or `lib/engine/score.ts`.
4. Every number the UI renders resolves to a `Ref`.
5. `now` is always a parameter. `Date.now()` appears only in React components and route handlers, never in the engine.
6. Missing data is `null` with a note. Never zero, never imputed, never estimated.
7. The shortlist is 3–5 companies, never one, capped at two per sector (relaxed to three only to reach three sectors), threshold 50.0.
8. No composite score is ever rendered.
9. XP is a closed whitelist: lesson 20, check 10, mission 30, quiz 15. Nothing else changes XP.
10. Manual values are labelled "manually transcribed". No label may imply an API produced a value a human typed.

## Decisions this plan fixes

The spec leaves these points either silent or internally inconsistent. Each is resolved once here, implemented that way everywhere, and anywhere the resolution adds a field or a block type it is listed.

| # | Issue in the spec | Decision |
|---|---|---|
| 1 | §5.1 forbids `lib/engine/*` from importing anything but types, yet §5.4 shows `classify` taking a `snapshot` and `answer.ts` needs one | The snapshot is passed in as data. `handleTurn(input, deps)` takes `deps: EngineDeps = { snapshot, rephrase? }`. `classify(message, profile, snapshot)`. No engine module imports `lib/data/snapshot.ts`. |
| 2 | §5.5 `Answer` has no way to return the profile the turn derived, so the UI cannot persist intake answers | `Answer.profileState: ProfileState \| null` is added: `{ profile: PartialProfile; assumed: ProfileField[]; missing: ProfileField[]; complete: boolean }`. |
| 3 | §6.2 requires a clarification question with up to four options, but §5.5's `Block` union has no block that can carry a non-intake question | A `choices` block is added: `{ type: "choices"; question: string; options: Option[] }`. Used only by the `clarify` route. |
| 4 | §6.4 item 5 requires a "How these were chosen" disclosure, but the `shortlist` block carries no weights | The `shortlist` block gains `howChosen: HowChosenView` and `diversityNote: string`. The union's block types are unchanged. |
| 5 | §5.6 rule 9 ("one covered stock and no other cue → `stock_detail`") would swallow rule 11 ("Should I buy Infosys?") | Rule 9 is implemented as "one covered stock and **no advice cue** and no other cue". Rule 11 therefore still fires. Documented in `classify.ts` and asserted in `tests/classify.test.ts`. |
| 6 | §7.6 says coverage is measured "before the missing weights are redistributed", and §7.6 step 3 says `w*` sums to 1 over non-null factors — both are true only if coverage is computed on the *renormalised* weights | Coverage = Σ(final normalised weights of factors with data). Redistribution renormalises those same weights across available factors. Both numbers come from `applyMultipliers` plus `redistribute`. |
| 7 | §7.5 lists valuation anchors for both P/E and P/B but does not say how many sub-scores valuation averages | Non-financial valuation averages two sub-scores (own-history P/E percentile, sector P/E premium). Financial valuation averages two (own-history P/B percentile, sector P/B premium). |
| 8 | §9.5 `safety.corpus.test.ts` needs composed answers for 10 cases × 12 stocks, but only some routes mention a stock | The corpus test composes every case, then composes a forced `stock_detail` turn for each of the 12 tickers in each locale. That is the 12-stock sweep. |
| 9 | §10.9's last assertion (H1 yields 3–5 qualifiers) is a data test but requires the engine | The coverage-table assertions live in `tests/data.contract.test.ts`; the "H1 and four variants yield 3–5 qualifiers" assertion lives in `tests/shortlist-coverage.test.ts`, which is where §13.9 already puts it. |
| 10 | The spec never gives numeric thresholds for risk flags beyond C4's D/E ≥ 0.3 and C7's drawdown > 20% | `RISK_THRESHOLDS` in `config.ts` holds them, `/method` renders them, and `tests/risk.test.ts` pins every boundary. They are labelled product judgements, like the anchors. |
| 11 | §8.1 unlock conditions reference artefacts ("first shortlist generated", "first chart viewed") that are not XP events | `EventType` includes non-XP events (`stock_viewed`, `chart_viewed`, `shortlist_generated`, `risk_named`, `quiz_completed`). `XP_SOURCES` maps only the four XP-bearing types, and a test asserts no other type changes XP. |
| 12 | Neither §10.4 nor §10.5 says where the sector names and the index series live for charting | `MetricSet` carries `sectorName`, `indexSeries` and `indexVolatilityPct`, resolved in `metrics.ts` from `Sector` and `IndexSeries`. |

```ts
  "Jan", "Feb", "Mar", "Apr", "May", "Jun",
  "Jul", "Aug", "Sep", "Oct", "Nov", "Dec",
] as const;

const MONTHS_LONG = [
  "January", "February", "March", "April", "May", "June",
  "July", "August", "September", "October", "November", "December",
] as const;

/** Indian digit grouping: 1,23,45,678. `dp` fixed decimals, default 0. */
export function indianGroup(value: number, dp = 0): string {
  const negative = value < 0;
  const fixed = Math.abs(value).toFixed(dp);
  const dot = fixed.indexOf(".");
  const intPart = dot === -1 ? fixed : fixed.slice(0, dot);
  const decPart = dot === -1 ? "" : fixed.slice(dot + 1);
  const last3 = intPart.slice(-3);
  let rest = intPart.slice(0, -3);
  const groups: string[] = [];
  while (rest.length > 2) {
    groups.unshift(rest.slice(-2));
    rest = rest.slice(0, -2);
  }
  if (rest.length > 0) groups.unshift(rest);
  const body = groups.length > 0 ? `${groups.join(",")},${last3}` : last3;
  return `${negative ? "-" : ""}${body}${decPart ? `.${decPart}` : ""}`;
}

/** Percentages: one decimal, §9.3. */
export function formatPercent(value: number, dp = 1): string {
  return `${value.toFixed(dp)}%`;
}

/** Signed percentage for one-session moves: "+1.2%" / "-1.0%". */
export function formatSignedPercent(value: number, dp = 1): string {
  const sign = value >= 0 ? "+" : "";
  return `${sign}${value.toFixed(dp)}%`;
}

/** Ratios: two decimals, §9.3. */
export function formatRatio(value: number, dp = 2): string {
  return value.toFixed(dp);
}

/** Times interest earned: one decimal with a trailing x. */
export function formatTimes(value: number, dp = 1): string {
  return `${value.toFixed(dp)}x`;
}

/** Crore values: Indian grouping, no decimals, §9.3. */
export function formatCrore(value: number): string {
  return indianGroup(value, 0);
}

/** Prices: two decimals with Indian grouping, §9.3. */
export function formatPrice(value: number): string {
  return indianGroup(value, 2);
}

/** "09 Nov 2026" from an ISO date or timestamp. */
export function formatDate(iso: string): string {
  const [year, month, day] = iso.slice(0, 10).split("-").map(Number);
  return `${String(day).padStart(2, "0")} ${MONTHS_SHORT[month - 1]} ${year}`;
}

/** "31 October 2026" — used inside narrative templates. */
export function formatDateLong(iso: string): string {
  const [year, month, day] = iso.slice(0, 10).split("-").map(Number);
  return `${day} ${MONTHS_LONG[month - 1]} ${year}`;
}

  month: "2-digit",
  day: "2-digit",

  return Math.round(value * 10) / 10;
}
```

```ts
/**
 * Canonical JSON: object keys sorted, no whitespace. Two structurally equal
 * values always produce the same string, which is what makes `scoreId` (§7.9)
 * reproducible across machines.
 */
export function canonicalJson(value: unknown): string {
  if (value === null || value === undefined) return "null";
  if (typeof value === "number") return Number.isFinite(value) ? String(value) : "null";
  if (typeof value === "string" || typeof value === "boolean") return JSON.stringify(value);
  if (Array.isArray(value)) return `[${value.map(canonicalJson).join(",")}]`;
  const obj = value as Record<string, unknown>;
  const keys = Object.keys(obj).sort();
  return `{${keys.map((k) => `${JSON.stringify(k)}:${canonicalJson(obj[k])}`).join(",")}}`;
}

/** FNV-1a, 32-bit, as eight lowercase hex characters. */
export function fnv1a(input: string): string {
  let hash = 0x811c9dc5;
  for (let i = 0; i < input.length; i += 1) {
    hash ^= input.charCodeAt(i);
    hash = Math.imul(hash, 0x01000193) >>> 0;
  }
  return hash.toString(16).padStart(8, "0");
}

/** The first eight hex characters of the FNV-1a hash of canonical JSON. */
export function shortHash(value: unknown): string {
  return fnv1a(canonicalJson(value));
}
```

```ts
/**
 * `Dated<T>` is the provenance unit from §10.2. Every number the UI can
 * display sits inside one. `value` may be null, and then `note` is required
 * and the UI renders "Not available" with that note.
 *
 * The schema is a factory so that `Dated<boolean>`, `Dated<string>` and

export type Dated<T> = {
  value: T | null;
  asOf: string;
  source: string;
  note?: string;
```

```ts
type SnapshotShape = z.infer<typeof baseSnapshotSchema>;

const DATE_FIELDS = new Set(["asOf", "publishedAt", "periodEnd", "effectiveDate", "listingDate"]);

function addIssue(ctx: z.RefinementCtx, path: (string | number)[], message: string) {
  ctx.addIssue({ code: "custom", path, message });
}

/** Every §10.8 refinement, in table order. */
export function refineSnapshot(snap: SnapshotShape, ctx: z.RefinementCtx) {
  const sourceIds = new Set(snap.sources.map((s) => s.id));
  const generatedAtDate = snap.generatedAt.slice(0, 10);

  // Tickers and ISINs are unique.
  const tickers = new Set<string>();
  const isins = new Set<string>();
  snap.stocks.forEach((stock, index) => {
    if (tickers.has(stock.ticker) || isins.has(stock.isin)) {
      addIssue(ctx, ["stocks", index], "Duplicate stock identity");
    }
    tickers.add(stock.ticker);
    isins.add(stock.isin);
  });

  // Every source and sourceId exists in sources[].
  const usedSources: Array<{ path: (string | number)[]; id: string }> = [];
  snap.stocks.forEach((stock, si) => {
    usedSources.push({ path: ["stocks", si, "nifty50Member", "source"], id: stock.nifty50Member.source });
    usedSources.push({ path: ["stocks", si, "businessSummary", "source"], id: stock.businessSummary.source });
    usedSources.push({ path: ["stocks", si, "segments", "source"], id: stock.segments.source });
    usedSources.push({ path: ["stocks", si, "prices", "source"], id: stock.prices.source });
    usedSources.push({ path: ["stocks", si, "recentPrices", "source"], id: stock.recentPrices.source });
    usedSources.push({ path: ["stocks", si, "financials", "annual", "source"], id: stock.financials.annual.source });
    stock.financials.annual.value.forEach((year, yi) => {
      usedSources.push({ path: ["stocks", si, "financials", "annual", "value", yi, "sourceId"], id: year.sourceId });
    });
    stock.corporateActions.forEach((action, ai) => {
      usedSources.push({ path: ["stocks", si, "corporateActions", ai, "sourceId"], id: action.sourceId });
    });
  });
  snap.sectors.forEach((sector, si) => {
    usedSources.push({ path: ["sectors", si, "description", "source"], id: sector.description.source });
    usedSources.push({ path: ["sectors", si, "medianPe", "source"], id: sector.medianPe.source });
    usedSources.push({ path: ["sectors", si, "medianPb", "source"], id: sector.medianPb.source });
  });
  snap.index.prices.value && usedSources.push({ path: ["index", "prices", "source"], id: snap.index.prices.source });
  usedSources.push({ path: ["index", "prices", "source"], id: snap.index.prices.source });
  snap.news.forEach((item, ni) => usedSources.push({ path: ["news", ni, "sourceId"], id: item.sourceId }));
  snap.exclusions.forEach((item, ei) => usedSources.push({ path: ["exclusions", ei, "sourceId"], id: item.sourceId }));

  for (const used of usedSources) {
    if (!sourceIds.has(used.id)) addIssue(ctx, used.path, `Unknown source: ${used.id}`);
  }

  // A Dated value of null has a non-empty note; nothing is dated in the future.
  const walk = (node: unknown, path: (string | number)[]) => {
    if (node === null || typeof node !== "object") return;
    if (Array.isArray(node)) {
      node.forEach((child, i) => walk(child, [...path, i]));
      return;
    }
    const record = node as Record<string, unknown>;
    if ("value" in record && "asOf" in record && "source" in record) {
      if (record.value === null && (typeof record.note !== "string" || record.note.trim() === "")) {
        addIssue(ctx, [...path, "value"], "Missing null explanation");
      }
    }
    for (const [key, child] of Object.entries(record)) {
      if (DATE_FIELDS.has(key) && typeof child === "string" && child.slice(0, 10) > generatedAtDate) {
        addIssue(ctx, [...path, key], "Future-dated or mislabelled value");
      }
      walk(child, [...path, key]);
    }
  };
  walk(snap, []);

  // Financial history: exactly five ascending, contiguous years; block asOf is the latest periodEnd.
  snap.stocks.forEach((stock, si) => {
    const years = stock.financials.annual.value;
    const path = ["stocks", si, "financials", "annual", "value"] as (string | number)[];
    if (years.length !== 5) {
      addIssue(ctx, path, "Financial history incomplete: exactly five annual periods are required");
      return;
    }
    const expected = [2022, 2023, 2024, 2025, 2026];
    years.forEach((year, yi) => {
      const yearNumber = Number(year.fy.slice(2));
      if (yearNumber !== expected[yi]) {
        addIssue(ctx, [...path, yi, "fy"], "Financial history incomplete: years must be FY2022 to FY2026, oldest first");
      }
      if (year.periodEnd.slice(0, 4) !== String(expected[yi])) {
        addIssue(ctx, [...path, yi, "periodEnd"], "Financial history incomplete: periodEnd does not match the FY label");
      }
    });
    const latest = years[years.length - 1].periodEnd;
    if (stock.financials.annual.asOf !== latest) {
      addIssue(ctx, ["stocks", si, "financials", "annual", "asOf"], "Future-dated or mislabelled value: financials asOf must equal the latest periodEnd");
    }
  });

  // Price granularity, ordering, contiguity and endpoint identity.
  snap.stocks.forEach((stock, si) => {
    const monthly = stock.prices.value;
    if (monthly.granularity !== "monthly_close" || stock.recentPrices.value.granularity !== "daily_close") {
      addIssue(ctx, ["stocks", si, "prices", "value", "granularity"], "Price series granularity invalid");
    }
    const points = monthly.points;
    if (points.length < 12) {
      addIssue(ctx, ["stocks", si, "prices", "value", "points"], "Price series invalid: at least 12 monthly points are required");
    }
    const months = new Set<string>();
    for (let i = 0; i < points.length; i += 1) {
      const month = points[i].date.slice(0, 7);
      if (months.has(month)) {
        addIssue(ctx, ["stocks", si, "prices", "value", "points", i, "date"], "Price series invalid: duplicate month");
      }
      months.add(month);
      if (i > 0 && points[i].date <= points[i - 1].date) {
        addIssue(ctx, ["stocks", si, "prices", "value", "points", i, "date"], "Price series invalid: dates must be ascending");
      }
    }
    if (points[points.length - 1]?.date !== stock.prices.asOf) {
      addIssue(ctx, ["stocks", si, "prices", "asOf"], "Price series invalid: the last point date must equal asOf");
    }

    const daily = stock.recentPrices.value.points;
    const dailyPath = ["stocks", si, "recentPrices", "value", "points"] as (string | number)[];
    if (daily.length < 10 || daily.length > 30) {
      addIssue(ctx, dailyPath, "Recent price series invalid: 10 to 30 daily points are required");
    }
    const days = new Set<string>();
    for (let i = 0; i < daily.length; i += 1) {
      if (days.has(daily[i].date)) {
        addIssue(ctx, [...dailyPath, i, "date"], "Recent price series invalid: duplicate trading day");
      }
      days.add(daily[i].date);
      if (i > 0 && daily[i].date <= daily[i - 1].date) {
        addIssue(ctx, [...dailyPath, i, "date"], "Recent price series invalid: dates must be ascending");
      }
    }
    if (daily[daily.length - 1]?.date !== stock.recentPrices.asOf) {
      addIssue(ctx, ["stocks", si, "recentPrices", "asOf"], "Recent price series invalid: the last point date must equal asOf");
    }
    if (stock.recentPrices.asOf >= generatedAtDate) {
      addIssue(ctx, ["stocks", si, "recentPrices", "asOf"], "Recent price series invalid: the last session must be completed before generatedAt");
    }
    if (stock.recentPrices.asOf < stock.prices.asOf) {
      addIssue(ctx, ["stocks", si, "recentPrices", "asOf"], "Recent series predates the monthly series");
    }
  });

  // Covered stocks need dated sector valuations.
  const sectorsById = new Map(snap.sectors.map((sector) => [sector.id, sector]));
  snap.stocks.forEach((stock, si) => {
    const sector = sectorsById.get(stock.sectorId);
    if (!sector) {
      addIssue(ctx, ["stocks", si, "sectorId"], `Unknown sector: ${stock.sectorId}`);
      return;
    }
    if (sector.medianPe.value === null || sector.medianPb.value === null) {
      addIssue(ctx, ["sectors"], "Sector valuation missing: every covered sector needs medianPe and medianPb");
    }
  });

  // Stock and index windows start within 31 days of each other.
  const indexStart = snap.index.prices.value?.points[0]?.date;
  if (indexStart) {
    snap.stocks.forEach((stock, si) => {
      const start = stock.prices.value.points[0]?.date;
      if (!start) return;
      const gapDays = Math.abs(Date.parse(start) - Date.parse(indexStart)) / 86_400_000;
      if (gapDays > 31) addIssue(ctx, ["stocks", si, "prices", "value", "points", 0], "Series not comparable: windows start more than 31 days apart");
    });
  }

  // At most one corporate action of each type per stock per year.
  snap.stocks.forEach((stock, si) => {
    const seen = new Set<string>();
    stock.corporateActions.forEach((action, ai) => {
      const key = `${action.type}:${action.effectiveDate.slice(0, 4)}`;
      if (seen.has(key)) {
        addIssue(ctx, ["stocks", si, "corporateActions", ai], "Duplicate corporate action");
      }
      seen.add(key);
    });
  });
}
```

```ts
import { readFile } from "node:fs/promises";
import path from "node:path";
import { snapshotSchema } from "../lib/data/schema";

type Report = {
  ok: boolean;
  lines: string[];
};

async function readSnapshot(file: string): Promise<unknown> {
  const text = await readFile(file, "utf8");
  return JSON.parse(text) as unknown;
}

function coverageLines(snap: ReturnType<typeof snapshotSchema.parse>): string[] {
  const sectorCounts = new Map<string, number>();
  for (const stock of snap.stocks) {
    sectorCounts.set(stock.sectorId, (sectorCounts.get(stock.sectorId) ?? 0) + 1);
  }
  const bySector = [...sectorCounts.entries()]
    .sort((a, b) => b[1] - a[1] || a[0].localeCompare(b[0]))
    .map(([id, count]) => `${id} ${count}`)
    .join(", ");

  const monthlyCounts = [...new Set(snap.stocks.map((s) => s.prices.value?.points.length ?? 0))];
  const dailyCounts = [...new Set(snap.stocks.map((s) => s.recentPrices.value?.points.length ?? 0))];
  const yearCounts = [...new Set(snap.stocks.map((s) => s.financials.annual.value.length))];
  const newsByTicker = new Map<string, number>();
  for (const item of snap.news) {
    if (!item.ticker) continue;
    newsByTicker.set(item.ticker, (newsByTicker.get(item.ticker) ?? 0) + 1);
  }
  const thinnestStockNews = Math.min(...snap.stocks.map((s) => newsByTicker.get(s.ticker) ?? 0));

  return [
    `Stocks: ${snap.stocks.length} | Sectors: ${sectorCounts.size} | News: ${snap.news.length} | Exclusions: ${snap.exclusions.length}`,
    `Sector distribution: ${bySector}`,
    `Monthly points per stock: ${monthlyCounts.join("/")} | Recent points per stock: ${dailyCounts.join("/")}`,
    `Financial years per stock: ${yearCounts.join("/")} | Fewest news items for a stock: ${thinnestStockNews}`,
    `Corporate actions: ${snap.stocks.reduce((n, s) => n + s.corporateActions.length, 0)}`,
    `Index points: ${snap.index.prices.value?.points.length ?? 0}`,
  ];
}

export async function checkSnapshot(file: string): Promise<Report> {
  let raw: unknown;
  try {
    raw = await readSnapshot(file);
  } catch (error) {
    return { ok: false, lines: [`Cannot read ${file}: ${(error as Error).message}`] };
  }

  const parsed = snapshotSchema.safeParse(raw);
  if (!parsed.success) {
    const lines = parsed.error.issues.slice(0, 40).map((issue) => {
      const where = issue.path.length > 0 ? issue.path.join(".") : "(root)";
      return `${where}: ${issue.message}`;
    });
    const total = parsed.error.issues.length;
    if (total > 40) lines.push(`… and ${total - 40} more issues`);
    return { ok: false, lines: [`${file}: ${total} validation issue(s)`, ...lines] };
  }

  return {
    ok: true,
    lines: [`Snapshot ${parsed.data.snapshotId} — valid`, ...coverageLines(parsed.data)],
  };
}

async function main() {
  const file = process.argv[2] ?? path.join("data", "snapshot.json");
  const report = await checkSnapshot(file);
  for (const line of report.lines) {
    if (report.ok) console.log(line);
    else console.error(line);
  }
  process.exit(report.ok ? 0 : 1);
}

if (process.argv[1] && process.argv[1].endsWith("check-data.ts")) {
  void main();
}
```

```ts
import rawSnapshot from "../../data/snapshot.json";
import { snapshotSchema, type Snapshot } from "./schema";

/** Recursively freeze a value graph. Exported so the freeze itself is testable. */
export function deepFreeze<T>(value: T): T {
  if (value === null || typeof value !== "object" || Object.isFrozen(value)) return value;
  Object.freeze(value);
  for (const child of Object.values(value as Record<string, unknown>)) {
    deepFreeze(child);
  }
  return value;
}

function formatIssues(issues: ReadonlyArray<{ path: PropertyKey[]; message: string }>): string {
  return issues
    .slice(0, 10)
    .map((issue) => `${issue.path.length > 0 ? issue.path.join(".") : "(root)"}: ${issue.message}`)
    .join("\n");
}

const parsed = snapshotSchema.safeParse(rawSnapshot);

if (!parsed.success) {
  throw new Error(
    `The data file failed validation.\n${formatIssues(parsed.error.issues)}\nRun: npm run data:check`,
  );
}

/** Validated once at module load and deep-frozen. There is no other data source. */
export const snapshot: Snapshot = deepFreeze(parsed.data);

export const snapshotId: string = snapshot.snapshotId;
```

```ts
import { formatDate, istDate } from "../engine/format";

export type FreshnessKind = "price" | "monthly_price" | "financials" | "news" | "static";
export type Freshness = "current" | "stale" | "expired";

/** Thresholds in calendar days from §10.7. `staleMax` is inclusive. */
export const FRESHNESS_THRESHOLDS: Record<FreshnessKind, { currentMax: number; staleMax: number }> = {
  price: { currentMax: 4, staleMax: 30 },
  monthly_price: { currentMax: 45, staleMax: 75 },
  financials: { currentMax: 400, staleMax: 550 },
  news: { currentMax: 30, staleMax: 90 },
  static: { currentMax: Number.POSITIVE_INFINITY, staleMax: Number.POSITIVE_INFINITY },
};

/** Whole IST calendar days from `asOf` to the instant `now`. Never negative. */
export function daysBetween(asOf: string, now: string): number {
  const from = Date.parse(`${asOf.slice(0, 10)}T00:00:00+05:30`);
  const to = Date.parse(`${istDate(now)}T00:00:00+05:30`);
  return Math.max(0, Math.round((to - from) / 86_400_000));
}

export function freshness(asOf: string, kind: FreshnessKind, now: string): Freshness {
  const age = daysBetween(asOf, now);
  const { currentMax, staleMax } = FRESHNESS_THRESHOLDS[kind];
  if (age <= currentMax) return "current";
  if (age <= staleMax) return "stale";
  return "expired";
}

export type DataBadge = {
  asOf: string;
  sourceLabel: string;
  freshness: Freshness;
  text: string;
  detail: string | null;
};

const EXPIRED_DETAIL: Partial<Record<FreshnessKind, string>> = {
  price: "This session is old; the figures shown use the latest monthly close.",
  monthly_price: "This figure is too old to use for fit. It is shown for learning only.",
  financials: "This figure is too old to use for fit. It is shown for learning only.",
  news: "This item is too old to show as recent.",
};

export function badgeFor(
  asOf: string,
  kind: FreshnessKind,
  now: string,
  sourceLabel: string,
): DataBadge {
  const state = freshness(asOf, kind, now);
  const age = daysBetween(asOf, now);
  let detail: string | null = null;
  if (state === "stale") {
    detail = `This figure is ${age} days old. Prices may have moved since.`;
  } else if (state === "expired") {
    detail = EXPIRED_DETAIL[kind] ?? null;
  }
  return {
    asOf,
    sourceLabel,
    freshness: state,
    text: `As of ${formatDate(asOf)} · ${sourceLabel}`,
    detail,
  };
}
```

```js
#!/usr/bin/env node
/**
 * Four-rung snapshot builder (§10.10). It never fabricates a value: a rung that
 * fails for a ticker falls through for that ticker only, and if every rung fails
 * the script writes data/manual-template.csv with the exact columns and exits 1.
 *
 * Rungs: 1 NSE bhavcopy, 2 Yahoo chart, 3 Stooq CSV, 4 manual template.
 * This machine blocks rungs 1 and 2 (Access Denied, HTTP 429); rung 3 may work.
 */
import { existsSync } from "node:fs";
import { mkdir, readFile, writeFile } from "node:fs/promises";
import { spawnSync } from "node:child_process";
import path from "node:path";

const ROOT = path.resolve(import.meta.dirname, "..");
const SNAPSHOT = path.join(ROOT, "data", "snapshot.json");
const MANUAL_TEMPLATE = path.join(ROOT, "data", "manual-template.csv");
const USER_AGENT = "BullPrototype/0.1 (course project; contact: team9@example.edu)";
const TIMEOUT_MS = 10_000;
const REQUEST_INTERVAL_MS = 1_000;

export const MANUAL_COLUMNS = [
  "ticker",
  "kind",
  "date",
  "close",
  "revenueCr",
  "ebitdaCr",
  "ebitCr",
  "patCr",
  "epsInr",
  "dpsInr",
  "netWorthCr",
  "totalDebtCr",
  "interestExpenseCr",
  "operatingCashFlowCr",
  "sharesOutstandingCr",
  "source_label",
];

const args = process.argv.slice(2);
const flag = (name) => args.includes(`--${name}`);
const option = (name) => {
  const hit = args.find((a) => a.startsWith(`--${name}=`));
  return hit ? hit.slice(name.length + 3) : null;
};

const sleep = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

async function fetchWithTimeout(url) {
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), TIMEOUT_MS);
  try {
    const response = await fetch(url, {
      signal: controller.signal,
      headers: { "user-agent": USER_AGENT, accept: "text/csv,application/json" },
    });
    return response;
  } finally {
    clearTimeout(timer);
  }
}

/** Rung 1: NSE bhavcopy. Returns null on Access Denied. */
export async function rungNse(ticker, date) {
  const stamp = date.replaceAll("-", "");
  const url = `https://archives.nseindia.com/products/content/sec_bhavdata_full_${stamp}.csv`;
  const response = await fetchWithTimeout(url);
  if (!response.ok) return null;
  const body = await response.text();
  if (!body.includes("SYMBOL")) return null;
  const line = body.split("\n").find((row) => row.startsWith(ticker));
  if (!line) return null;
  const cells = line.split(",");
  return { rung: "nse", close: Number(cells[6]), label: `NSE bhavcopy ${date}` };
}

/** Rung 2: Yahoo Finance chart endpoint. Returns null on HTTP 429. */
export async function rungYahoo(ticker, range = "5y") {
  const url = `https://query1.finance.yahoo.com/v8/finance/chart/${ticker}.NS?range=${range}&interval=1mo`;
  const response = await fetchWithTimeout(url);
  if (!response.ok) return null;
  const json = await response.json();
  const result = json?.chart?.result?.[0];
  if (!result) return null;
  const points = (result.timestamp ?? []).map((ts, i) => ({
    date: new Date(ts * 1000).toISOString().slice(0, 10),
    close: result.indicators.quote[0].close[i],
  })).filter((p) => typeof p.close === "number");
  return points.length > 0 ? { rung: "yahoo", points, label: "Yahoo Finance chart" } : null;
}

/** Rung 3: Stooq CSV. Returns null when the symbol is unknown. */
export function parseStooqCsv(body) {
  const lines = body.trim().split("\n");
  if (lines.length < 2) return [];
  const points = [];
  for (const line of lines.slice(1)) {
    const [date, open, high, low, close] = line.split(",");
    if (!date || !close) continue;
    const value = Number(close);
    if (Number.isFinite(value) && value > 0) points.push({ date, close: value });
  }
  return points;
}

export async function rungStooq(ticker, from, to) {
  const url = `https://stooq.com/q/d/l/?s=${ticker.toLowerCase()}.in&d1=${from.replaceAll("-", "")}&d2=${to.replaceAll("-", "")}&i=m`;
  const response = await fetchWithTimeout(url);
  if (!response.ok) return null;
  const points = parseStooqCsv(await response.text());
  return points.length > 0 ? { rung: "stooq", points, label: "Stooq CSV" } : null;
}

/** The manual CSV template. Every row must carry the transcription phrase and date. */
export function manualTemplateCsv(tickers, date) {
  const header = MANUAL_COLUMNS.join(",");
  const rows = [];
  for (const ticker of tickers) {
    rows.push(`${ticker},monthly_close,YYYY-MM-DD,,${",".repeat(10)},Screener.in — manually transcribed ${date}`);
    rows.push(`${ticker},daily_close,YYYY-MM-DD,,${",".repeat(10)},Google Finance — manually transcribed ${date}`);
    rows.push(`${ticker},annual,FY2026,${",".repeat(11)},Company annual report — manually transcribed ${date}`);
  }
  return `${[header, ...rows].join("\n")}\n`;
}

function sourceRecord(id, label, publisher, url, method) {
  return {
    id,
    label,
    publisher,
    url,
    retrievedAt: `${new Date().toISOString().slice(0, 10)}T18:30:00+05:30`,
    method,
    licence: method === "derived" ? "derived" : "personal_research",
    note: method === "manual_transcription" ? "Hand-typed from the page named in the label." : null,
  };
}

async function main() {
  if (flag("check")) {
    const result = spawnSync("npx", ["tsx", "scripts/check-data.ts"], { cwd: ROOT, stdio: "inherit" });
    process.exit(result.status ?? 1);
  }

  if (existsSync(SNAPSHOT) && !flag("force")) {
    console.error(`${SNAPSHOT} exists. Re-run with --force to overwrite.`);
    process.exit(1);
  }

  const only = option("only");
  const tickers = only ? only.split(",").map((t) => t.trim().toUpperCase()) : null;
  if (!tickers) {
    console.error("Pass --only=TICKER[,TICKER] so the builder knows which companies to fetch.");
    console.error("The covered set is chosen by the data owner against the NSE list (§10.9).");
    process.exit(1);
  }

  const from = option("from") ?? "2021-11-30";
  const to = option("to") ?? "2026-10-31";
  const dryRun = flag("dry-run");
  const results = [];
  const manual = [];

  for (const ticker of tickers) {
    let record = null;
    for (const [name, rung] of [
      ["nse", () => rungNse(ticker, to)],
      ["yahoo", () => rungYahoo(ticker)],
      ["stooq", () => rungStooq(ticker, from, to)],
    ]) {
      try {
        record = await rung();
      } catch (error) {
        console.error(`${ticker}: rung ${name} failed — ${error.message}`);
        record = null;
      }
      await sleep(REQUEST_INTERVAL_MS);
      if (record) {
        record.ticker = ticker;
        break;
      }
    }
    if (record) {
      results.push(record);
      console.log(`${ticker}: ${record.rung} — ${record.label}`);
    } else {
      manual.push(ticker);
      console.log(`${ticker}: every rung failed — needs manual transcription`);
    }
  }

  if (manual.length > 0) {
    const csv = manualTemplateCsv(manual, "2026-11-10");
    if (dryRun) {
      console.log(csv);
    } else {
      await mkdir(path.dirname(MANUAL_TEMPLATE), { recursive: true });
      await writeFile(MANUAL_TEMPLATE, csv, "utf8");
    }
    console.error(
      `\n${manual.length} ticker(s) need manual transcription. Fill ${MANUAL_TEMPLATE} from Screener.in and Google Finance,\n` +
        `keeping the phrase "manually transcribed" and the date in source_label. Then build data/snapshot.json by hand\n` +
        `and run: npm run data:check. The builder will not write placeholder values.`,
    );
    process.exit(1);
  }

  const payload = {
    generatedBy: results.every((r) => r.rung === "nse" || r.rung === "yahoo" || r.rung === "stooq") ? "api" : "manual_transcription",
    generatedAt: new Date().toISOString(),
    sources: [
      sourceRecord("manual:screener.in:2026-11-10", "Screener.in — manually transcribed 10 Nov 2026", "Screener.in", null, "manual_transcription"),
    ],
    prices: results.map((r) => ({ ticker: r.ticker, points: r.points ?? [], rung: r.rung })),
    note: "Raw price facts only. The builder does not compute ratios.",
  };

  if (dryRun) {
    console.log(JSON.stringify(payload, null, 2));
    return;
  }
  await mkdir(path.dirname(SNAPSHOT), { recursive: true });
  await writeFile(SNAPSHOT, `${JSON.stringify(payload, null, 2)}\n`, "utf8");
  console.log(`Wrote ${SNAPSHOT}`);
}

if (process.argv[1] && process.argv[1].endsWith("build-snapshot.mjs")) {
  await main();
}
```

```ts
import { formatCrore, formatPercent, formatPrice, formatRatio, formatTimes } from "@/lib/engine/format";

export function createDataRef(id: string, value: number | string, unit: RefUnit, asOf: string, source: string): Ref {
  return { kind: "data", id, value, unit, asOf, source };
}

export function createDerivedRef(id: string, value: number | string, unit: RefUnit, formulaId: string, inputRefIds: string[]): Ref {
  return { kind: "derived", id, value, unit, formulaId, inputRefIds };
}

export function createConfigRef(id: string, value: number | string, unit: RefUnit): Ref {
  return { kind: "config", id, value, unit };
}

export function createProfileRef(id: string, value: string, displayValue: string): Ref {
  return { kind: "profile", id, value, displayValue };
}

export function formatRefValue(ref: Ref): string {
  if (typeof ref.value === "string") return ref.value;
  switch (ref.unit) {
    case "price": return formatPrice(ref.value);
    case "percent": return formatPercent(ref.value);
    case "ratio": return formatRatio(ref.value);
    case "crore": return formatCrore(ref.value);
    case "times": return formatTimes(ref.value);
    case "score": return formatRatio(ref.value, 1);
    default: return String(ref.value);
  }
}
```

```ts
import { describe, expect, it } from "vitest";
import * as fs from "node:fs";
import * as path from "node:path";

function findFiles(dir: string, ext: string): string[] {
  if (!fs.existsSync(dir)) return [];
  const entries = fs.readdirSync(dir, { withFileTypes: true });
  const files: string[] = [];
  for (const entry of entries) {
    const full = path.join(dir, entry.name);
    if (entry.isDirectory()) {
      files.push(...findFiles(full, ext));
    } else if (entry.name.endsWith(ext)) {
      files.push(full);
    }
  }
  return files;
}

describe("engine purity contract", () => {
  it("lib/engine never imports React, Next, fs, fetch, process.env, or lib/llm", () => {
    const files = findFiles(path.resolve("lib/engine"), ".ts");
    const forbidden = ["react", "next/", "node:fs", "node:fetch", "process.env", "lib/llm", "@/lib/llm"];
    for (const file of files) {
      const content = fs.readFileSync(file, "utf8");
      for (const pattern of forbidden) {
        expect(content, `${path.basename(file)} imports ${pattern}`).not.toContain(pattern);
      }
    }
  });

  it("components never import narrative.ts, metrics.ts, or score.ts directly", () => {
    const files = [...findFiles(path.resolve("components"), ".tsx"), ...findFiles(path.resolve("components"), ".ts")];
    const forbidden = ["narrative", "metrics", "score"];
    for (const file of files) {
      const content = fs.readFileSync(file, "utf8");
      for (const pattern of forbidden) {
        const importRegex = new RegExp(`from\\s+['"].*lib/engine/${pattern}['"]`);
        expect(importRegex.test(content), `${path.basename(file)} directly imports ${pattern}`).toBe(false);
      }
    }
  });
});
```

## Execution Handoff

Plan complete and saved to `docs/superpowers/plans/2026-11-10-bull-v0.md`. Please review the plan. Which execution approach would you prefer?

- **Subagent-driven** - A fresh subagent implements each task and a fresh reviewer checks it before the next one starts, then a whole-branch review at the end. Most thorough; costs a fresh context per task and per review.
- **Native** - I implement every task myself in this session, the way this harness runs work, then one fresh reviewer on the most capable model checks the whole branch. Cheapest and fastest; no independent review until the end. Runs well with a mid-tier session model, since the plan carries the design.

For this plan I recommend **Subagent-driven**, because there are 74 structured tasks with strict TDD cycles, distinct engine/data/component boundaries, and an unyielding ship gate where independent review on each task prevents drift from the spec. Does the plan capture what you want, and which approach should we use?
